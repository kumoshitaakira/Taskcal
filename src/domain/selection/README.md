# src/domain/selection

**担当B** — 候補評価と勤務計画の選定（RFC-012 §3.1、作業U03）。

守る規則（RFC-009 §6、D01〜D04）：

- 承諾時間を自動で短縮しない。
- 実行可能な計画だけを選定する。「有効な承諾すべての和集合で覆われる」ことと
  「同時に採用できる合法な勤務集合がある」ことは別。1つのbooleanへ詰め込まない。
- 選定できる承諾は最新の有効版だけ。確認中、期限切れ、撤回、未処理変更ありのものを
  確定しない（D04）。
- 欠勤者本人を代替候補から除く（D01）。
- 過去の辞退を候補順位の減点に使わない（ADR-008）。
- 優先順位：勤務時間合計 → 人数 → 承諾が揃った順 → 安定ID順。

未決：Q02（必要人数を「ちょうど1人」とするか「最低1人・超過許容」とするか）。
A16の期待値はQ02を決めてから固定する。

関連する受入ケース：A16、A11。
