# src/agent

**担当A** — 観測、返信解釈、次行動の選択、費用記録（作業U08）。未実装。

境界（ADR-004、AGENTS.md）：

- モデルは返信解釈と、許可された次行動の提案だけを行う。
- 本人確認、認可、候補適格性、時間、承諾、上限、予算、状態遷移は
  決定的なコードで検査する。
- 外部の返信は引用されたデータとして扱い、system指示と同じ権限を与えない。
- 遅れて返ったモデル結果で、新しい承諾を過去の状態へ戻さない（A12）。

プロンプト、schema、モデルID、Router設定、温度、最大出力、入力例を版管理する（RFC-004）。

## 現在の呼出し元

`src/application/interpret-reply.ts`。モデルへ渡すのは、打診の提示条件・現在の承諾・
確定前後・返信本文（マスク後）だけで、実名・連絡先は入れない（ADR-008）。

モデルの出力をそのまま採用しない。次を決定的なコードで検査する。

- 提示した区間の中に収まること（D03）
- 区間が1つであること（Q03：分断は範囲外。丸めない）
- 15分刻み、最長4時間（Q10）
- 日跨ぎでないこと（Q05）
- 未解決の条件が残っていないこと（Q09：自己申告を同意の証拠にしない）
- 期限内であること

遅れて返った結果は、受信順（`last_applied_seq`）で弾く。保存はするが適用しない（A12）。
