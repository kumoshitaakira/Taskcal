# ADR-004：AIは解釈と限定行動選択を行い、確定権限を持たせない

> 2026-09-20継続注記：AIの提案とコードによる実行検査の責任分離は継続。自然文承諾の新方針は[ADR-014](ADR-014-natural-consent.md)に記録しました。

日付：2026-09-19／状態：設計上の暫定決定  
詳細：[RFC-004](../rfc/RFC-004-agent-router.md)

## 背景

自由文を理解する柔軟性は必要だが、LLM出力だけで本人の同意、勤務制約、実行許可を判断すると、誤解釈や指示注入がシフト確定へ直結する。毎ステップ店長に承認を求めると自律性の価値が薄れる。

## 決定

単一エージェントが状態を観測し、返信を構造化し、合法な選択肢から次行動を提案する。候補順位、区間充足、同意成立、権限、期限、予算、DB更新はコードで検査する。モデルにSQL、任意URL、ルール変更、宛先自由指定を渡さない。

店長の開始操作で範囲を委任し、その範囲内は追加承認なしで進める。スタッフ本人の条件同意は必須。次行動が一意ならコードで遷移し、毎回LLMを呼ばない。

## 選択肢

自由な汎用ツールエージェントは表現力が高いが保証範囲が広すぎる。全ルールベースは安全性を作りやすいが自由文の条件理解が限定される。全件店長承認はP2の現場試行には使うが、H0で示す自律ループの既定にはしない。

## 結果と不利益

勤務の安全性をモデルの推論力に依存させにくくなる。一方、業務状態機械と合法actionを人が設計するコストが必要。AIが何でも交渉できる製品ではない。

## 検証・見直し

E03/E07/E13/E14で部分可否・曖昧さ・攻撃・不正出力を確認する。新しいツールを追加する際は、権限、入力、重複、停止、費用、結果観測を新RFCで定義してから許可する。
