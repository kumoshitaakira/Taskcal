# ADR-020：サービス名をTaskcalとし、専用リポジトリへ記録を移管する

日付：2026-09-20／状態：ユーザー決定済み  
関連：[リポジトリREADME](../../README.md)、[設計索引](../README.md)

## 背景

これまで「案05」「欠勤リカバリー」として設計・レビューを進めていた。ユーザーがサービス名をTaskcalとし、作成したTaskcalリポジトリへの成果物移動を指示した。

## 決定

サービス名はTaskcalとする。現行の概要・設計索引・以後の文書はこの名称を使う。ADR・RFC・未決事項・出典・提供資料・レビューをdocs配下に置く。企画比較資料とスライド、移管前の配布ZIPも履歴として保管する。

## 代替と理由

仮称を継続する案や名称候補の比較は行わない。ユーザーの明示した名称を採用する。文書を会話の作業場所だけに置く方式から、実装と同じリポジトリで版管理できる構成へ移す。

## 帰結

過去ADRの本文、添付原文、過去のスライド・ZIPは、当時の名称と判断を保持する。名称変更のために過去の決定理由を書き換えない。未決事項やレビュー提案の採用状態は変わらない。

この作業はローカルリポジトリへのファイル移管であり、Gitのcommit・pushや公開を含まない。名称の商標・ドメイン調査を実施したという意味でもない。

## 確認

READMEから現行設計へ移動できること、ADR・RFC間の相対リンク、成果物の移管先での一致を確認する。名称を変更する場合は後続ADRで置換する。
