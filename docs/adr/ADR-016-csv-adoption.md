# ADR-016：CSV出力と正式採用を分け、正式版参照を一括更新する

> 2026-09-21確定注記：Q01を確定し、本ADRの案A（アプリ管理下のデモ勤務表への正式採用）を採用しました。以下の「提案する決定」は採用済みの決定として扱います。案Bを選んだ場合の扱いは適用されません。記録は[未決事項](../OPEN-QUESTIONS.md)の「確定した選択」にあります。

日付：2026-09-20／状態：提案、Q01の選択待ち。承認済み決定ではない  
詳細：[RFC-010](../rfc/RFC-010-csv-authority.md)／関連する過去判断：[ADR-006](ADR-006-idempotency.md)

## 背景

更新CSVを作るだけでは、次案件や再起動で元CSVへ戻る可能性がある。反対に変更案出力を正式勤務と表示すると、反映していない勤務を確定扱いにする。

## 提案する決定

アプリ管理下の不変なCSV版を作り、正式版参照を持つ。作業用出力を作成・検査した後、期待版・案件・承諾を再検査し、正式版参照と内部確定事実を一括採用する。元CSVは履歴として残す。正式採用前の成果物は勤務に数えない。

## 選択肢

| 案 | 判断 |
|---|---|
| A：デモ勤務表として正式採用 | 自律確定を示す目的に合うため推奨 |
| B：変更案CSVのみ出力 | 小さく作れるが、勤務への自律反映は完了しない。成果を出力完了に変更するなら可 |
| 元CSVを直接上書き | 変更前保持というv0.4方針に反するため選ばない |

## 帰結

正式版メタデータと操作結果の永続化が必要。ファイルとDBを単一取引で更新できるとは仮定しない。準備済み未採用ファイルの整理が必要だが、二重確定や旧版への復帰を防ぎやすい。
