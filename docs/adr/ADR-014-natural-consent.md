# ADR-014：一意に解釈できる自然文返信を承諾として扱う

> 2026-09-21確定注記：Q09を確定しました。判定対象は返信単体ではなく、元打診・現在の承諾・確定前後の状態を含みます。対応文型の一覧だけで判定しません。「承諾として採用しない」ことと「返信を無視する」ことは別に扱います。記録は[未決事項](../OPEN-QUESTIONS.md)の「確定した選択」にあります。

日付：2026-09-20／状態：自然文承諾は現行方針、成立・保留の詳細はレビュー反映案  
詳細：[RFC-011](../rfc/RFC-011-outreach-and-state.md)／部分置換：[ADR-005](ADR-005-consent-intervals.md)

## 背景

旧案は全件の構造化同意を要求した。v0.2以降は、元の打診と返信から意思と時間が一意に定まり検査を通る場合、確定に使える承諾とする。

## 記録する方針

全件に専用ボタンを要求しない。採用したReplyInterpretationをCommitmentから参照する。条件が変わる場合は新しいCommitmentと置換関係を作り、本人の時間を無断で短縮しない。

## レビュー反映案

打診は回答の確定効力を明示する。条件不明・訂正確認中・未処理の新しい返信がある間は確定を保留する。最新の適用順は永続受信と訂正関係から決め、AI完了順では決めない。Q09で対応文型と追加確認への境界を選ぶ。

## 選択肢と帰結

構造化同意は解釈の境界が作りやすい。自然文は相手の操作を減らせる可能性がある一方、条件の見落としがリスクになる。schema・時刻検査だけで意味の正しさを保証できないため、曖昧な入力は確認へ戻す。

## 検証・見直し

A05/A12と自然文fixtureで、旧承諾の復活や未処理訂正の無視がないことを確認。安全に扱える文型が狭すぎる場合は確認ボタン併用を再検討する。ADR-005の「完全一致する時間」「全体一括確定」は撤回しない。
