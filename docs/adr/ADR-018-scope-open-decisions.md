# ADR-018：充足・時間範囲・月次集計の未決判断を分離する

日付：2026-09-20／状態：未決判断の記録。いずれかの案を採用済みとはしない  
詳細：[RFC-009](../rfc/RFC-009-domain-v04.md)、[未決事項](../OPEN-QUESTIONS.md)

## 背景

v0.2〜v0.4では、過剰配置、分断時間、日跨ぎ、部分欠勤、月次集計の説明が変化・省略された。旧文書の値を自動的に現行仕様とすると、異なる期待値で実装・試験を進めてしまう。

## 今回記録する扱い

| 判断 | 候補 | 状態 |
|---|---|---|
| Q02 過剰配置 | 各区間ちょうど1人／最低1人で超過上限付き | 未決。ちょうど1人を初期推奨 |
| Q03 分断時間 | 区間集合／分断入力を拒否 | 未決。4日間は拒否を初期推奨 |
| Q04 部分欠勤 | 部分区間を差引く／元勤務全体だけ対象 | 未決。全体欠勤のみを初期推奨 |
| Q05 日跨ぎ | 隣接営業日も検査／日跨ぎを拒否 | 未決。日跨ぎ拒否を初期推奨 |
| Q06 月次上限 | 実績＋予定／完了済みも予定区間で集計 | 未決。実績を持たないMVPは後者を初期推奨 |

## 選択理由と帰結

初期推奨は実装範囲を小さくするためで、現場で十分だという証拠ではない。範囲を広げるなら該当する反例と工数を追加する。月次上限を将来予定だけに限定するなら、月全体の就労上限とは別の名称・意味に変更する。

## 検証・更新方法

選択後にQ番号・判断日・理由を追記し、A09/A10/A16/A17の期待値を固定する。今の不明点を「レビューで決定済み」としない。
