# ADR-013：適格スタッフ全員へ個別に同時打診する

日付：2026-09-20／状態：v0.2〜v0.4に明記された現行設計方針、未実装  
詳細：[RFC-011](../rfc/RFC-011-outreach-and-state.md)／置換：旧RFC-001/002の順次打診方針

## 背景

旧案は一人ずつ連絡したが、現行案は全員への個別同時打診を採る。返信を待つ相手が複数になるため、候補順位と相手別状態の責任を変える必要がある。

## 決定として記録する方針

適格者全員へ個別に打診する。グループチャットは使わない。Outreachは相手別の対話を持ち、案件内で複数が並行する。全枠が成立する選定が得られたら、最新条件で確定へ進む。

## 選択肢と理由

順次打診は通知数を抑えられる一方、無応答待ちが積み重なる。今回の文書は応答の並行性を選んだ。速度向上の実測はまだなく、選択理由の期待と成果を区別する。

## 帰結

通知量、同時返信、複数の承諾、未採用者への終了通知が増える。一人への確認が案件全体を停止させない状態設計が必要。辞退を将来の不利益な順位に使わない。

## 検証・見直し

A11で一人の確認不能と全体成立を分離する。連絡数・応答時間・スタッフ負担を測る。順次方式へ戻す場合は本ADRを新しい判断で置換し、旧仕様を黙って再利用しない。
